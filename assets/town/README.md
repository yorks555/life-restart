# 小镇素材

本目录的 `character.svg` 与 `js/town-scene.js` 中的建筑、树木、道路、居民等均为本项目原创绘制，无第三方图片、字体或外部素材下载依赖。

窗口中的建筑缩略图直接从同一张小镇场景裁切；`js/game-art.js` 提供原创像素 SVG 图标。事件、地点、活动与图鉴共用这些素材，避免混用不同画风。

根目录的 `favicon.svg`、`icon-192.png` 和 `icon-512.png` 使用同一原创像素小屋图案，供浏览器标签、安装图标、页头与载入界面使用。

桌面场景使用固定 1000 × 700 坐标，与同一坐标系的可访问建筑按钮对齐。人生路线与固定建筑一一对应；路线事件仍由本局存档种子决定，地图位置不随机。

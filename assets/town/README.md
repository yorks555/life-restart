# 小镇素材

本目录的 `character.svg` 与 `js/town-renderer.js` 中的建筑、树木、道路、居民等均为本项目原创绘制，无第三方图片、字体或外部素材下载依赖。

窗口中的建筑缩略图直接从同一张小镇场景裁切；`js/game-art.js` 提供原创柔线 SVG 图标。事件、地点、活动与图鉴共用这些素材，避免混用不同画风。

根目录的 `favicon.svg`、`icon-192.png` 和 `icon-512.png` 使用同一原创淡彩小屋图案，供浏览器标签、安装图标、页头与载入界面使用。

桌面场景使用固定 1620 × 1100 世界坐标，桌面与手机共用地图。摄像机只改变屏幕投影，与同一世界坐标系的可访问建筑 / 事件按钮对齐。人生事件与区域池对应；路线事件仍由本局存档种子决定，地图位置不随机。

画风与比例见 `ART-DIRECTION.md`，代表性素材与五阶段角色预览见 `style-study.html`。角色头像和地图人物共用 `TownRenderer.character`，静态 character.svg 仅作启动时的备用头像。

# 栖迟小镇 · 美术规范

现代东方小镇，淡彩绘本；米白纸、草木绿、暖木、灰蓝与少量砖红。道路偏暖、水体偏蓝，避免整幅画统一蒙灰。

- 视角：统一轻俯视，屋顶、桌面和长椅上面可见；人物脚底为世界位置。
- 光照：左上照亮，右下落影。阴影透明、柔和，不使用纯黑。
- 线条：灰绿 / 暖棕约 1–2 个世界单位，圆角与曲线；不使用像素锯齿。
- 尺度：成人约 54 个世界单位，门高 40，房屋宽 130–150，树高 75–110，主路宽 44。
- 建筑：住宅瓦顶、书屋窗与书架、商铺遮阳棚、茶馆廊架、工坊锯齿顶、车站候车棚、观星屋圆顶；不能仅更换颜色。
- 植被：阔叶、银杏、松、柳、开花树；灌木与小花为辅，密林作为未开放边界。
- UI：保留纸张、留白、细线，作为世界上的轻浮层；可以收起角色与手记。
- 角色：同一绘制函数生成地图人物与头像。童年、少年、青年、中年、晚年通过身高、衣着、发色与姿态区别；外观不参与规则或 RNG。

素材均由项目原创 Canvas / SVG 绘制，无外部字体、贴图或许可证依赖。环境纹理由坐标产生，独立于人生 Seed。

# 🎐 人生重启研究所 · Life Restart

> 栖迟小镇：面向桌面浏览器的生活肉鸽。固定小镇场景、角色状态、人生手记与事件对话。纯属娱乐。

**零依赖、零构建**，全部原生 HTML / CSS / JavaScript，继续兼容 GitHub Pages。主场景、活动窗口、图鉴和旅人档案共用暖纸色、草木绿和原创像素素材。

## ✨ 桌面游戏结构

- 🏠 **首页**：固定小镇，左侧角色面板，中央可探索场景，右侧人生手记；推荐 1366×768 及更大桌面窗口。
- 🏘️ **小镇探索**：点击地面自动绕开房屋与池塘行走；点击建筑、路线或地点手册会先走到门口再打开。方向键 / WASD 随时接管，Esc 停止自动行走；靠近建筑按 E 或点击互动提示。角色有方向与行走动画。先查看地点，再选择推进人生或闲逛活动。移动和闲逛不耗资源；事件未选择时可返回重选路线，已完成的选择保存结果。
- 📜 **活动窗口**：五子棋、抽签等玩法在小镇内打开，关闭后返回原位置。同一活动关闭再打开保留当前状态。旧工具网址自动进入对应窗口，旧图鉴与档案链接仍可访问。
- 🧑 **旅人档案**：统一窗口管理昵称、生日和累计记录；与原有工具共用本地存档。
- 📖 **图鉴**：收集 44 项（签文 / 人生成就 / 生肖 / 棋局成就 / 人生结局），玩的过程中自动解锁
- ▧ **随身物品**：显示事件中获得的收音机、股份约定等剧情线索。

## 🎮 七个玩法

| 玩法 | 说明 |
|---|---|
| ⚫ **命运棋局** | 15×15 无禁手五子棋，休闲/挑战人机、同屏双人、选点确认、悔棋、自动续局、人机战绩和 3 个图鉴成就。 |
| 🔄 **人生重开** | 3 种出身、8 个天赋（初始 6 个）、30 个事件、15 步路线选择和 8 个结局。支持中途续局；经典随机版保留在 life-classic.html。 |
| 🔮 **今日命运** | 每日命势 + 农历 / 生肖 / 节气，同一天同一人固定。 |
| 🧧 **命运排盘** | 排四柱、纳音五行、五行缺补、生肖冲合（解锁生肖图鉴）。 |
| 🎋 **命运抽签** | 求一支签，上上/上吉/中平/下下（解锁签文图鉴）。 |
| 🪙 **人生统计** | 人生进度条 + 游戏化调侃文案。 |
| 🏘️ **栖迟小镇** | 固定的六处路线建筑与树下棋摊；主页、人生、小镇三个入口共用桌面游戏壳。 |

## 🎨 主题

- **桌面游戏**：暖纸色、草木绿、原创像素场景，无外部字体下载。
- **活动与图鉴**：共用纸张窗口、像素图标和建筑缩略图；活动界面统一为暖色主题。
- **启动与标识**：浏览器标签、安装图标、页头与载入画面共用像素小屋。载入完成自动进入游戏，初始化失败可重新载入；支持系统的减少动态效果偏好。

## 🚀 本地运行

- 方式一：浏览器打开 `index.html`。
- 方式二（推荐，实时刷新）：VSCode 装 Live Server，右键 → Open with Live Server。
- 方式三（命令行）：`npx serve .`

## 🧰 技术栈

- 原生 HTML + CSS + JavaScript（零依赖、无框架）
- Canvas 2D + WebAudio + localStorage（本地数据）
- Service Worker / PWA（可安装到桌面 · 离线可用，网络优先策略）

## 五子棋验证

运行 `node --test tests/gomoku.test.cjs tests/gomoku-ui.test.cjs` 检查胜负、边界、悔棋、续局、人机攻防、重复计分及切换设置。人机默认玩家执黑；挑战难度会评估下一手反击，不代表专业棋力。战绩和棋局仅保存到本地浏览器。

## 人生肉鸽

`index.html`、`life.html`、`pixel-town.html` 共用 `js/game-shell.js`、`css/game-desktop.css` 和 `js/town-scene.js` 的桌面界面。场景与人物为本项目原创绘制，无外部图片或字体依赖。旧版人生保存在 `life-classic.html`。每阶段三步、五阶段，体力或心情耗尽会提前结束。候选天赋、事件和概率结果由本局种子决定，存档通过重放选择恢复，刷新不会改变已发生的结果。局外只解锁天赋候选与结局图鉴，不加永久属性。场景与建筑位置固定，不随人生重开改变。

运行 `node --test tests/*.test.cjs` 验证五子棋、人生成长、存档重放、天赋、资源边界、阶段推进、固定地图、桌面场景碰撞、旧网址兼容与事件返回的一致性。

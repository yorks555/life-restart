# 🎐 人生重启研究所 · Life Restart

> 栖迟小镇：支持桌面与移动模式的生活肉鸽。固定小镇场景、角色状态、人生手记与事件对话。纯属娱乐。

**零依赖、零构建**，全部原生 HTML / CSS / JavaScript，继续兼容 GitHub Pages。主场景、活动窗口、图鉴和旅人档案共用暖纸色、草木绿和原创淡彩绘本素材。

## 本次更新与打开方式

这次更新整合了大地图、淡彩绘本画风、桌面 / 手机双模式和居民生活系统。详细新增内容与操作说明见 [更新记录](CHANGELOG.md)。

日常游玩直接打开 [栖迟小镇](https://yorks555.github.io/life-restart/)。更新上传后，等待 GitHub Pages 部署完成，再刷新页面即可。存档属于当前浏览器和网址；本地预览与线上网站的存档互相独立。

本地开发预览：在项目文件夹打开 PowerShell，执行 `python -m http.server 8784 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8784/index.html`，保持终端窗口开着。

## ✨ 桌面游戏结构

- 🏠 **首页**：固定小镇，左侧角色面板，中央可探索场景，右侧人生手记；桌面推荐 1366×768 及更大窗口；手机使用专门的状态简栏、地图和底部操作区。
- 🏘️ **小镇探索**：点击地面自动绕开房屋与池塘行走；点击建筑、路线或地点手册会先走到门口再打开。方向键 / WASD 随时接管，Esc 停止自动行走；靠近建筑按 E 或点击互动提示。角色有方向与行走动画。先查看地点，再选择推进人生或闲逛活动。移动和闲逛不耗资源；事件未选择时可返回重选路线，已完成的选择保存结果。
- 📜 **活动窗口**：五子棋、抽签等玩法在小镇内打开，关闭后返回原位置。同一活动关闭再打开保留当前状态。旧工具网址自动进入对应窗口，旧图鉴与档案链接仍可访问。
- 🧑 **旅人档案**：统一窗口管理昵称、生日和累计记录；与原有工具共用本地存档。
- 📖 **图鉴**：收集 52 项（小镇人物 / 签文 / 人生成就 / 生肖 / 棋局成就 / 人生结局），玩的过程中自动解锁
- ▧ **随身物品**：显示事件中获得的收音机、股份约定等剧情线索。

## 大地图与双模式更新

- 固定世界为 **1620 × 1100**，面积约为原地图的 2.5 倍；七个区域、十一处地点，共用移动、碰撞和寻路。森林与河流保留扩建边界。
- 摄像机跟随旅人，桌面视野更宽，手机使用更近的视野；全图可查看区域、玩家、目标与已发现地点。
- 新人生使用区域事件池：到学校、商街、公园等不同区域，会抽取不同的现有事件。30 个事件全部保留，阶段、Flag 前置、权重与已访问状态决定候选池。地图 ! / ? / ✦ 提供探索入口，快捷路线仍然保留。
- 八个途中事件，单个人生步数最多检查一次、整局最多发生五次，同一个途中事件不重复。移动本身不耗属性；途中选择产生小幅变化，不占 15 个人生步数。
- 设置中选择 **自动 / 桌面版 / 移动版**，立即布局且保留手动偏好。模式只影响视野和界面，完全不参与游戏 RNG。移动版支持点击寻路、抵达后互动、角色/背包/手记面板、竖屏与横屏、安全区。
- `life_rogue_v1` 保留原键，外层已升级 `schemaVersion: 3`（兼容旧版 2），保存位置、区域、目标、发现地点及途中行进距离。旧 Engine v1 存档按原规则继续结束；新人生使用 Engine v2 (`map-v1`)。新旧存档均通过重放验证，损坏的局部地图状态安全降级，图鉴与档案保留。
- 界面偏好单独存于 `displayMode`。切换、旋转和刷新不会重抽当前事件、重复奖励或改变角色资源。
- PWA 核心资源缓存包含新地图、摄像机、显示模式、存档模块；设置可查看离线准备状态。仍为纯 HTML/CSS/JS，无新增依赖、后端或框架。

## 人生肉鸽

`index.html`、`life.html`、`pixel-town.html` 共用 `js/game-shell.js`、`css/game-desktop.css` 和 `js/town-scene.js` 的桌面界面。场景与人物为本项目原创绘制，无外部图片或字体依赖。旧版人生保存在 `life-classic.html`。每阶段三步、五阶段，体力或心情耗尽会提前结束。候选天赋、事件和概率结果由本局种子决定，存档通过重放选择恢复，刷新不会改变已发生的结果。局外只解锁天赋候选与结局图鉴，不加永久属性。场景与建筑位置固定，不随人生重开改变。表现层在 `town-renderer.js`：统一轻俯视、左上光源、灰绿柔线、五种树与不同建筑类型。地图人物与档案头像共用绘制函数，随童年、少年、青年、中年、晚年同步变化；阶段外观由 Run 派生，不参与存档随机规则。桌面地图铺满主区域，角色与手记为可展开 / 收起的纸张浮层。美术规范和代表性样张见 `assets/town/ART-DIRECTION.md` 与 `assets/town/style-study.html`。地图数据在 `town-map.js`，摄像机在 `town-camera.js`，事件标记在 `town-events.js`，显示模式与存档迁移各自独立。

运行 `node --test tests/*.test.cjs` 验证五子棋、人生成长、存档重放、天赋、资源边界、阶段推进、固定地图、桌面场景碰撞、旧网址兼容与事件返回的一致性。

## 居民生活

小镇有八位固定居民：林叔、夏禾、陈伯、余青、周岚、何溪、乔安和偶尔路过的无名旅人。每人拥有住处、性格、居民关系和六个时段的日程。虚拟时间每 90 秒活动推进一个时段，人生每一步也推进一个时段；窗口、后台和加载期间暂停，没有现实时间补算。住宅、棋摊与长椅支持坐到下一时段，不提供资源奖励。

居民沿玩家共用的碰撞与寻路地图实际走路，目的地变化才计算路径，离开视野不绘制角色。日程变化通过 `Seed + 居民 + 天数 + 人生阶段` 的独立哈希决定，不消耗人生随机序列。靠近按 E 或点击交谈，远处点击先自动走近。居民会自主碰面聊天，附近玩家可以听到旧路线索。玩家待机看看四周，也可以看公告栏和池塘。

每位居民有认识、帮忙或拒绝、隔至少两个人生阶段后重逢的短故事。关系显示陌生 / 认识 / 熟悉 / 亲近 / 重要的人，重复聊天和已完成故事不重复加关系或奖励。夏禾青年时在外求学，中年返乡教学并换住处；林叔退休后更多时间坐在棋摊。熟悉余青会开放商业事件的额外选项，认识周岚会改变途中偶遇概率；棋友记得合法的五子棋胜局。普通人生和三位居民建立深厚关系时，叙事呈现「有人记得你」，仍计入原普通人生图鉴。

`game-time.js` 管理时段；`npc-data.js` 定义居民；`npc-system.js` 管理日程、移动、居民互动；`npc-dialogue.js` 处理条件台词；`npc-events.js` 管理故事、记忆和关系；`npc-ui.js` 连接地图与纸张对话窗口。人物志可以从地图或旅途图鉴打开，逐步揭露信息。没有在线 AI、后端或跨周目记忆。

存档 schemaVersion 3 保留 schemaVersion 2 地图和旧 Run。居民位置、虚拟时间、正在说话的短状态与线索持久化；路径、日程目标、外观和关系由数据、Seed 与 Run 动作重建。居民决定使用 `living-v1` 重放规则，旧 `map-v1` 和版本 1 的事件结果继续保留。损坏的居民坐标单独重置，不影响正常人生与图鉴。新增测试覆盖日程、碰撞、暂停、Seed、记忆、故事分支、棋局、身份变化、迁移与结局。

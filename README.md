# 🔄 人生重开模拟器 · Life Restart

> 对现在的人生不满意？那就重开一把！纯属娱乐，切勿当真 😎

一个写着玩的三合一整活网站。**零依赖、零构建**，全部原生 HTML / CSS / JavaScript，双击 `index.html` 就能跑。

## ✨ 三个玩法

| | 玩法 | 亮点 |
|---|---|---|
| 🔄 | **人生重开模拟器** | 随机投胎、随机天赋，从童年到老年体验五段人生，领一个离谱的结局和 S~D 评级。一键复制人生总结、下载分享卡片。 |
| 🔮 | **今日抽象运势** | 输入名字和星座，生成一本正经胡说八道的今日运势。首页自带今日农历（干支纪年 + 生肖 + 节气），同一天同一人结果固定——这就是命；也可以「换一签」逆天改命。 |
| 🧧 | **八字排盘** | 输入出生日期与时辰，排出四柱八字（年 / 月 / 日 / 时柱），带农历生日、生肖和五行分布。 |
| 🏘️ | **像素小镇生成器** | 每次生成一座独一无二的像素小镇，记下编号就能还原同一座。 |

## 🚀 本地运行

方式一：直接用浏览器打开 `index.html`。

方式二（推荐，实时刷新）：VSCode 装 Live Server 插件，右键 → Open with Live Server。

方式三（命令行）：

```bash
npx serve .
```

## 🧰 技术栈

- 原生 HTML + CSS + JavaScript（零依赖、无框架）
- Canvas 2D：绘制人生总结卡片、运势卡片、像素小镇
- 种子随机算法：同样的种子 → 同样的结果（运势按天固定、小镇按编号还原）

# 🎐 整活小站 · Life Restart

> 一个写着玩的玄学 / 整活小站。打开首页，选一个模块开工！纯属娱乐 😎

**零依赖、零构建**，全部原生 HTML / CSS / JavaScript，双击 `index.html` 进入首页。

## ✨ 首页 & 六个模块

首页是模块选择页，点卡片进入对应玩法：

| | 模块 | 玩法 |
|---|---|---|
| 🔄 | **人生重开模拟器** | 随机投胎、随机天赋，从童年到老年体验五段人生，领一个离谱的结局和 S~D 评级。一键复制人生总结、下载分享卡片。 |
| 🔮 | **今日抽象运势** | 输入名字和星座，生成一本正经胡说八道的今日运势。自带今日农历（干支纪年 + 生肖 + 节气），同一天同一人结果固定；也可以「换一签」改命。 |
| 🧧 | **八字排盘** | 输入出生日期与时辰，排出四柱八字、纳音五行、五行缺补与生肖相冲相合，带农历生日。 |
| 🎋 | **抽签祈福** | 心里想一件事，摇一支签，上上 / 上吉 / 中平 / 下下签，配搞笑解签与分享卡片。 |
| 🪙 | **人生进度条** | 输入生日，看看人生已经走过多少，配一句调侃文案与分享卡片。 |
| 🏘️ | **像素小镇生成器** | 每次生成一座独一无二的像素小镇，记下编号就能还原同一座。 |

## 🚀 本地运行

- 方式一：直接用浏览器打开 `index.html`（首页）。
- 方式二（推荐，实时刷新）：VSCode 装 Live Server 插件，右键 → Open with Live Server。
- 方式三（命令行）：`npx serve .`

## 🧰 技术栈

- 原生 HTML + CSS + JavaScript（零依赖、无框架）
- Canvas 2D：绘制人生总结卡片、运势卡片、签文卡片、人生进度卡片、像素小镇
- 种子随机算法：同样的种子 → 同样的结果（运势按天固定、小镇按编号还原）
- 深蓝色主题，全站平涂统一

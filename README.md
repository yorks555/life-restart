# 🎐 人生重启研究所 · Life Restart

> 一个可爱又神秘的人生模拟 App。打开首页，像一个 App 一样探索你的命运实验室！纯属娱乐 😎

**零依赖、零构建**，全部原生 HTML / CSS / JavaScript。默认**浅色主题**，支持**深色模式**切换。

## ✨ App 结构

- 🏠 **首页**：问候 + 我的档案（生肖/年龄/人生进度）+ 今日命运（幸运指数/数字）
- ✨🎮 **命运实验室**（中间突出按钮）：点击弹出六个玩法
- 📖 **图鉴**：收集 33 项（签文 / 人生成就 / 生肖），玩的过程中自动解锁
- 🪪 **我的**：人生统计（成就 / 图鉴 / 重开次数 / 最高评级）+ 设置（音效 / 深色模式）

## 🎮 六个玩法

| 玩法 | 说明 |
|---|---|
| 🔄 **人生重开** | 随机投胎、五段人生，领 S~D 评级与成就。记录重开次数、最高评级、成就图鉴。 |
| 🔮 **今日命运** | 每日命势 + 农历 / 生肖 / 节气，同一天同一人固定。 |
| 🧧 **命运排盘** | 排四柱、纳音五行、五行缺补、生肖冲合（解锁生肖图鉴）。 |
| 🎋 **命运抽签** | 求一支签，上上/上吉/中平/下下（解锁签文图鉴）。 |
| 🪙 **人生统计** | 人生进度条 + 游戏化调侃文案。 |
| 🏘️ **平行世界** | 生成独一无二的像素小镇，编号可还原。 |

## 🎨 主题

- **默认浅色**：白/淡灰底 + 主紫 `#6C63FF` + 青蓝 `#55C7E8` + 成功 `#5BC98A`
- **深色模式**：保留深蓝紫，一键切换，全站生效并记住

## 🚀 本地运行

- 方式一：浏览器打开 `index.html`。
- 方式二（推荐，实时刷新）：VSCode 装 Live Server，右键 → Open with Live Server。
- 方式三（命令行）：`npx serve .`

## 🧰 技术栈

- 原生 HTML + CSS + JavaScript（零依赖、无框架）
- Canvas 2D + WebAudio + localStorage（本地数据）
- Service Worker / PWA（可安装到桌面 · 离线可用，网络优先策略）
